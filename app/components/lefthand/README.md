# 左手ポジション図解アセット

Arcoda の学びレッスン／技法解説で使う、左手のポジション図解とポジション移動アニメーション。

弓アセット（`violin-geometry.ts` / `bowing-motions.ts` / `BowingDemo.tsx`）と同じ設計思想・同じインターフェースで作られている。

---

## 設計の核 — d の一元管理

運弓が「h（毛のどの位置が弦に接するか）」の時系列で定義されるのと同様に、
**ポジション移動は「d（シフト量）の時系列」という 1 つの数値で定義される。**

d から、指・掌・胴オーバーレイのすべての座標変換が導出される。

```
指塊・爪・指しわ = translate(-34 + d, -1.69 + d × 0.0497)
手パス・手しわ  = translate(-49 + d, -2.54 + d × 0.0519)
```

> **パーツごとに動きを作り込んではならない。** 破綻の原因になる。

⚠️ y 係数が異なるのは、弦の傾き(0.0497)とネック下縁の傾き(0.0519)が異なるため。
**片方だけ動かすと、掌がネックから浮いて絵が壊れる。**

## ポジション定義

| ポジション | d | 胴オーバーレイ | 親指がネック裏 |
|---|---|:---:|:---:|
| 1st | 0 | – | – |
| 2nd | 68 | – | – |
| 3rd | 170 | ✓ | – |
| 4th | 272 | ✓ | – |
| 5th | 340 | ✓ | ✓ |
| 6th | 391 | ✓ | ✓ |

指幅 1 本分 = 68px。

**5th / 6th は親指がネック裏に回るため、`handTransform` では作れない。**
専用の最終座標パス（`HAND_BEHIND_NECK_PATH`）を使う。移動時は到達点でクロスフェードして持ち替えを表現する。

## 実装上の注意（重要）

### 胴オーバーレイは常時表示してはならない
3rd 以上では掌が胴に重なるため、胴を手前に再描画する必要がある。
ただし**常時表示すると、1st 位置にある前腕を覆ってしまう**。
`overlayOpacityKeyframes()` により、手が胴の領域に達してから現れるようにしてある。

### 指の傾きを反転させるとき、鏡映は禁止
`scale(-1,1)` を使うと**指の並び順まで反転**し、人差し指が右端に来てしまう。
指先ライン(y=305)を固定した剪断を使うこと: `matrix(1,0,-0.42,1,128.1,0)`

### 前腕を回転させてはならない
手ごと回転させると指と掌が分断される。前腕の角度（45°）はパス自体に焼き込まれている。

### 手パスの `L 458,371` 以降を削ってはならない
この区間（掌上縁 → 水かきの窪み → 親指の内縁）が、掌上縁とネック下縁の「一本線」を成立させている。

---

## 不変条件（改変したら必ず確認）

1. **掌上縁とネック下縁の「一本線」**: 掌の上端が `y = 365 + (x - 345) × 0.0519` に載る（残差 ≤3px）
2. 指先が弦の上に着地している
3. 浮かせ指の直下に背景の空白がない
4. 手が単一の連結成分（分断していない）

### 既知の「欠陥ではない」検出
ピクセル検査で「囲まれた背景」として検出されるが、いずれも意図した構造:
- ナット部: 15px
- 水かき（親指と人差し指の谷）: 139〜151px
- ミスパターンの水かき: 233〜312px（親指が取り残されて掌が浮く表現）

## アクセシビリティ

- 全 SVG に `role="img"` と `aria-label` を設定
- `prefers-reduced-motion: reduce` でアニメーションを無効化
- `playing={false}` で停止（静止画として正しく表示される）

---

## 検証方法

改変したら以下を実行すること。

1. **XML 検証**: 構文チェック（文字列置換の事故が多い）
2. **ピクセル逆測定**:
   - 軸角は**縁の直線回帰**で測る（窓 PCA は窓形状を測ってしまい誤判定する）
   - 弧の曲がりは**矢高**（弦からの最大距離）で測る
   - 切れ目は**フラッドフィル**で「外周から到達できない背景」を検出
   - しわの検出色は不透明度 0.5 の合成色 ≈ RGB(223,173,130)
3. **実地再現テスト**: 要件定義書から SVG を抽出 → レンダリング → 元画像と差分ゼロを確認
