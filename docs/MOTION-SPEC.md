## A. ページ（ギャラリー）側の演出

**A1 オーロラ背景の呼吸**
ページ全体に紺（左上）・金（右上）・紺（下部中央）の3層 radial-gradient を敷き、18秒周期の alternate アニメーションで不透明度 0.85→1.0 とスケール 1→1.06 を往復。背景がゆっくり「生きている」ように見える。

**A2 フィルムグレイン**
SVG の feTurbulence ノイズを data URI で全面に敷設。opacity 5%、mix-blend-mode: overlay。フィルム的な質感で暗部を締める。

**A3 ギャラリータイトルの光沢流れ（シーン）**
見出し文字を「白→金→白」の横グラデーション（background-size 220%）で塗り、8秒周期で背景位置を流して文字面に光が走り続ける。

**A4 タイトル下光彩**
タイトルに 0 2px 30px rgba(217,169,60,.25) の金のぼかし影。

## B. 端末フレーム（.phone）側の演出

**B1 端末の浮遊**
7秒周期の ease-in-out で上下に −7px ふわふわ浮く（translate アニメーション）。奇数番目の端末は −3.5秒の位相ずらしで、12台が一斉に動かず波のように見える。

**B2 3Dチルト（マウス追従）**
ホバー中、カーソル位置から perspective(1400px) の rotateX ±5°・rotateY ±7° を計算して端末が傾く。離れると 0.5秒かけて元に戻る（cubic-bezier(.2,.8,.25,1)）。

**B3 ホバー時の金縁グロー**
ホバーで外周ラインが金 rgba(232,178,60,.55) に変わり、落影が深化＋60px の金グローが追加される。

**B4 ノッチ＋ベゼル**
静止要素だが演出の一部として：10px の黒ベゼル、上部中央に Dynamic Island 風の丸角バー（104×24px）。

## C. 画面内コンテンツの出現演出

**C1 スタッガード出現**
端末がビューポートに入ると（IntersectionObserver・threshold .05）、その端末内の見出し・サブコピー・カード・セグメント・グリッドが 70ms ずつ時差（最大560ms）で下から16px浮上しながらフェードイン。0.7秒・cubic-bezier(.2,.8,.25,1)。

**C2 数字のカウントアップ**
.bigN（93点・95・88・42 等）が発火時に 0→実値へ 1.3秒・立方イージングで数え上げる。※`<b>` を含む Lv.7 は対象外（崩れ防止の修正済み）。

**C3 ランクリングの回転描画**
Lv.7 の円が発火時に 0%→66% へ 1.4秒で描かれる（CSS @property --p ＋ conic-gradient のトランジション）。

## D. 画面内の常駐モーション（常時ループ）

**D1 波形バーの律動**
採点波形の17本のバーが 2.6秒周期で高さ 82%↔106%・明度 90%↔112% を呼吸。各バーに −0.22s 刻みの位相差（JSで index 付与）を与え、波が伝播するように見せる。

**D2 注目バーの発光脈動**
発光指定（12〜18秒）の2本だけ、金の box-shadow が 1.8秒周期で強弱（14px→26px）するホットパルス。

**D3 RECボタンの呼吸**
録音ボタンが 2.4秒周期で金のリングを外へ放出（box-shadow が 0→16px に拡散して消える）。「録音待機中」の生命感。

**D4 金面の光沢スイープ**
CTAボタン・金のランクピル（S）・進捗バーの塗り部分に、白い光帯（skewX −18°）が 2.8〜3.4秒周期で左→右に走り続ける。

**D5 タブバー アクティブのグロー**
選択中タブのアイコンに drop-shadow(0 0 6px 金) の常時発光。

## E. インタラクション演出（ユーザーの操作に反応）

**E1 カードのスポットライト**
カード上のカーソル位置に 220px 径の金の光（radial-gradient）がリアルタイム追従。離れると 0.4秒でフェードアウト。

**E2 カードの縁取り変化**
ホバー中、カードのボーダーが金 rgba(217,169,60,.30) に変わる。

**E3' 上品な押下マイクロインタラクション (2026-08-21 リバイス8 ・ Tetsuo提供仕様に全面置換)**
対象: button ・ role=button ・ a ・ .pressable (全画面共通)。ネイビー #16294F ×ゴールド #D9A93C。
派手なリップル ・ 過度な拡大 ・ バウンド ・ 発光は使わない。サイズ/角丸/文字/レイアウトは不変。
- 押下 (pointerdown即時): 0.975倍 + 下1px + 外影を弱める + 明度0.96 +
  薄い金の光 rgba(217,169,60,.18) を約220msで内側に広げる (inset shadow)
- 戻り: 約200msのCSS transitionで滑らかに (Framer Motion未導入のためCSS実装)
- ホバー (hover対応端末のみ): 上1px + 明度1.04 + 影をわずかに強く。押下より控えめ
- focus-visible: 外側2pxの金リング (outline #D9A93C / offset 2px)。Enter/Spaceでも同じ押下感
- disabled は押下/ホバーとも動かない。reduced-motion は動きを止め色と不透明度のみ
- 非同期ボタン: 共通部品 AppButton.tsx (二重送信防止 / 幅固定のまま スピナー+処理中 /
  aria-busy / 非遷移の成功時のみ ✓完了 700ms / 遷移時は演出を待たない / エラーは直下に具体文)
- 旧E3 (沈み+ばね) ・ E4 (ボタン浮き出し) ・ B3押下グローはこの仕様に置換して廃止。
  B2チルトはカードのみに戻す (ボタン類はこの押下仕様が担当)

## F. 光・質感の静的演出（視覚効果として実装）

**F1 クリーム数字のグロー**
.bigN に 0 0 24px rgba(255,243,220,.28) の淡い内光。暗地で数字がほのかに滲む。

**F2 手紙カードの金縁＋外光**
アルコの語りカード（#FFF3DC）に金の1px内縁・44px のクリーム外光・深い落影を重ね、「暗地に置かれた1通の手紙」の存在感を強化。

**F3 カードのグラデーション層**
全カードが #1E3053→#15233F の上明るい垂直グラデ（光が上から当たる擬態）。

**F4 画面内の右上光彩**
各画面の右上に青の radial-gradient 円（420px）を敷き、基準モックの「上部の光」を再現。

**F5 チェック丸の薄塗り発色**
軸色 rgba 16% の薄塗り円＋同色✓（gold/teal/green/pink の4系統）。

**F6 変化量ピルの発色**
+4.8 等を軸色 13% 薄塗り＋上向き↗アイコン付きピル。

**F7 波形の曲線重畳**
発光波形の上に金のベジェ曲線（トレンドライン）を1.5px・90%不透明で重ねる。

**F8 タイポグラフィ統一**
Zen Kaku Gothic New（400/700/900）を Webフォントで導入し環境差を排除。

## G. 堅牢化・フォールバック機構（見えないが重要な演出制御）

**G1 プログレッシブエンハンスメント**
カードを隠すのは html.anim クラス（JSが正常起動した証）があるときだけ。JS非動作環境では最初から全表示。

**G2 例外時の自己回復**
JS全体を try-catch で包み、エラー時は anim を剥がして静止の完成形に自動退避。

**G3 IntersectionObserver 非対応フォールバック**
非対応ブラウザでは即時全表示。

**G4 強制表示タイマー**
発火漏れの保険として 2.5秒後に全端末へ .on を強制付与。

**G5 rootMargin 調整**
0px 0px 60px で画面下端より手前から発火し、スクロール時に「出る前に出始める」自然さを確保。

**G6 prefers-reduced-motion 完全対応**
システムが「視差効果を減らす」の場合、全アニメーション・トランジションを停止し、静的な完成形のみ表示。

**2026-08-21 リバイス10 — B2 の例外 (Tetsuo指示)**

  長押しドラッグでカードが傾き、上下にズレて見えるため。レールは選択/コールアウトも無効。

**2026-08-21 リバイス11 — E5 レールの時差追従スクロール (Tetsuo提供仕様)**
- 横レールは一括スライドせず、各カードが「自分の番号×28ms前のスクロール位置」を
  やわらかく追従する。移動中のみ隣接カードに最大8pxのズレ。停止すると先頭カードから

**2026-08-21 実装是正 (仕様変更ではない)**
- 遅延描画 (fetch後に発火済みカードへ入る中身) は、原本 v5 play() と同じ
  「reset → 下ごしらえ → 発火」で**カードごと再生し直す**。発火だけのやり直しでは
