## 🐛 発見した本物のバグ (修正済み・本番反映 911fabf)

**Stripe Webhook が認証ミドルウェアに 401 で遮断され、課金反映が全く動かない状態だった。**
- `middleware.ts` が `/api/*` 全てに認証を要求 → cookie を持たない Stripe からの webhook POST が署名検証に到達する前に 401
- 影響: **加入・トライアル開始・解約・支払い失敗のすべてが User に反映されない** (Phase 2 の心臓が止まっていた)
- 発見: 不正署名テストで期待の 400 でなく 401 が返ったことから逆算
- 修正: `PUBLIC_API_PATHS` に `/api/stripe/webhook` を追加 (認証は route 内の署名検証が担う)
- **これは Vercel に env 設定後の実カードE2Eで初めて表面化するはずだった潜在バグ。事前に潰せた。**
