# 9a 横画面録音モード 実装計画・影響対処・テスト要件 v1

作成: 2026-08-15 / 前提: ARC-SPEC-NATIVE-1.0 §9a (スコープ4点確定済)

## 1. 進め方 (2026-08-15 Tetsuo指示で確定)

**Windows完結で開発・検証 → 最後にMacで殻反映 → 実機テスト** の順。

- 開発用スイッチ: URLクエリ `?recband=1` が付いているときだけ、録音全画面を
  横画面モードのレイアウト・帯譜面・横スクロールで動かす (向きロックは呼ばない)。
  PCブラウザの横長ウィンドウ / iPhone Safariを手で横に倒して検証する
- 本番挙動: スイッチ無しのWeb版は縦のまま完全不変。アプリ版は
  isNativeApp() && 向きロック成功 のときだけ横モード
- Mac作業 (プラグイン同梱+plist) は Windows側の開発検証が終わってから実施

## 2. 影響範囲別の対処方法 (具体)

| # | 影響範囲 | 対処の実装方法 | 残リスク |
|---|---|---|---|
| 1 | 教材ページ | scoreDetailを共用しているため**追加実装不要** (practiceItemId経由で自動カバー)。確認のみ | 低 |
| 2 | 区間録音 | 横スクロール計画を「区間ノートのx範囲」に制限。区間末尾の自動停止は既存の実時間長計算 (楽譜時間×楽譜bpm/録音bpm+バッファ) をそのまま使う。区間ハイライトは帯描画後のnote要素の実座標から再計算 | 中: 区間端でのスクロール停止位置の見た目調整が実機依存 |
| 3 | パート練習 | 区間と同一機構 (partIdは区間の別名)。追加実装なし | 低 |
| 4 | 注釈・添削マーク | 座標は音符要素のgetBoundingClientRectから毎回計算する既存方式のため、**帯レイアウトでも再計算すれば正しく出る**。帯への切替後にanchor再計算をトリガ (既存のresize/mutation経路に乗せる) | 中: 帯は横に非常に長いためマークのfixed/absolute基準の取り違えに注意 |
| 5 | 採点色つけ | collectElements→色再適用はMutationObserverで再描画のたび走る既存機構。帯再renderでも発火する。note_index対応は時間順で不変 | 低 |
| 6 | 録音コア回帰 | 横モードはレイアウトとスクロールだけの分岐にし、**録音開始/停止/FLAC/アップロードのコードパスは一切分岐させない** | 低 |
| 7 | 回転ロック解除漏れ | unlock呼び出しを (a)停止 (b)キャンセル (c)recordingError (d)interruption (e)コンポーネントunmount (f)pagehide の6経路に配置。unlockは冪等 | 中: OSレベルの強制終了は救えない (再起動で縦に戻るため実害なし) |
| 8 | 横向きセーフエリア | バー・譜面コンテナに env(safe-area-inset-left/right) を適用 | 低 |
| 9 | プレビュー遷移 | stop→unlock完了→setStatus("preview") の順に直列化。回転アニメ中の連打はnativeFinalizingRefで既に抑止済 | 低 |
| 10 | 拡大ビュー/オンボ/祝い | 録音開始時に拡大ビュー自動クローズ済。他は録音終了後=縦復帰後の表示のため干渉なし。回帰テストで確認 | 低 |
| 11 | 縦スクロール計画との二重化 | 時刻→対象ノートの解決を共通関数に抽出し、縦=scrollTop / 横=scrollLeft の投影だけ分ける | 低 |
| 12 | iPad | UIRequiresFullScreen=YES で向きロックを有効化 (Mac作業に織込済)。レイアウトは同一CSS | 中: iPadの帯の見え方 (縦幅余り) は実機で微調整前提 |

## 3. テスト要件

### A. Web版回帰 (スイッチ無し・変化ゼロ確認) — PC Chrome + iPhone Safari
- [ ] 通し録音 (縦全画面・自動スクロール・視覚ビート・停止)
- [ ] 区間録音・パート録音 (ハイライト・部分採点)
- [ ] 教材録音 (音階)
- [ ] 注釈の表示・添削オーバーレイ・採点色つけ
- [ ] 拡大ビュー (ひろげる→とじる)
- [ ] 録音後: プレビュー→送信→採点→アルコ結果

### B. 横画面モード機能 (Windows開発中・?recband=1) — PCブラウザ横長 + iPhone Safari横倒し
- [ ] 帯譜面が1本で描画される (曲・音階の両方)
- [ ] カウントイン4拍→ガイド線が左10%・視覚ビートがその真上で拍動
- [ ] 横自動スクロールがBPMに追従 (BPM変更時も)
- [ ] 弾き終わり側が流れ、先の小節が右に見えている
- [ ] 区間録音: 区間だけ流れ、区間端で自動停止
- [ ] 注釈・添削マークが帯上の正しい音符位置に出る
- [ ] 採点色つけが帯でも正しい音符に付く (履歴レビューは対象外=録音中のみの確認)
- [ ] 停止バー: 経過時間・BPM・停止が機能
- [ ] 10分上限・末尾1.5秒自動停止

### C. アプリ実機 iPhone (Mac反映後)
- [ ] 録音開始→横固定→カウントイン→録音→停止→縦復帰
- [ ] キャンセル・電話割り込み・バックグラウンド化それぞれで縦復帰
- [ ] FLAC 48kHz/16bit/monoで保存・採点done (回帰)
- [ ] ノッチ側のセーフエリア (左右) にUIが食い込まない
- [ ] 録音経路6経路すべてで向きロック解除を確認

### D. アプリ実機 iPad
- [ ] 向きロックが効く (UIRequiresFullScreen)
- [ ] 帯レイアウトの縦幅バランス (崩れがないこと・微調整はここで)
- [ ] C同様の回転復帰・FLAC回帰

### E. 9b認証 (殻v2反映後・別トラック)
- [ ] アプリ: Googleログイン→アプリ内認証ブラウザ→アプリに戻ってログイン完了
