## 確定ルール (実装時の正)

- ガイド=実画面の上のオーバーレイ1部品: 暗幕+金の光(次に押す場所)+灰枠(いま見る場所)
  +道しるべバー(アルコ+一言+進捗pips)+現在地チップ+スキップ常設
- 「次へ」ボタンは存在しない。遷移=実物タップのみ。確認はガイドカード自身のボタン。
  押す物がない場面は約3秒で自動送り。タップ波紋+画面スライドイン。
- 核サイクル: 聴く→弾く→採点結果→ふりかえり→ホーム反映→基礎練→再挑戦
- 失敗ブランチ: 低得点=前向き言い換え / 無音=原因2行+もう一回
- WelcomeSlides と PageCoachMarks はこのガイド完成時に廃止・置換する

## 追加の徹底事項 (2026-08-29 Tetsuo指示)

1. **デモ方式で確定**: ランクにより表示曲が異なる+実演奏は時間がかかるため、
   デモ曲 (きらきら星) 固定・「弾いたてい」(録音→カウントダウン→デモの72点) で進める。
   デモはDBに演奏データを一切書かない (副作用ゼロ)。終了後は通常ホームに着地するだけで
   「戻す」処理は存在しない。本物は進行の保存とごほうびカード付与のみ。
2. **透明カバーの残留禁止**: 暗幕・光・灰枠は pointer-events:none。ガイド終了で
   DOM からアンマウント (GuideOverlay.dom.test で担保)。
3. **表示は初回1回だけ**: 進行・完了はサーバー(DB)保存。localStorage 禁止
   (WelcomeSlides の端末跨ぎ再表示の欠陥を繰り返さない)。完了/スキップ後は二度と出ない。
4. **道しるべバーはビューポート下端固定** (タブバーの上・スクロールで流れない)。
   光は対象要素に追従し、対象が画面下部のときはバーが上部へ退避。
   録音中・全画面中はガイド層ごと非表示。
