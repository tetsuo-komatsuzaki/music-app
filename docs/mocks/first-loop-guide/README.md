## 約束 (2026-08-29 Tetsuo指示)

このモックをそのままコードに落とし込み、実装に使用する。
**最終的に実装画面とモック画面に誤差がないかを突き合わせて確認する。**

## 大原則

1. **デモ方式**: デモ曲きらきら星固定・「弾いたてい」(録音タップ→3・2・1→帯モードデモ→結果)。
   DBに演奏データを一切書かない。本物は進行の保存とごほうび (達成カード) 付与のみ。
   終了後は通常ホームに着地 (「戻す」処理は存在しない)。
2. **画面はすべて実装に存在するものだけ**: 実スクリーンショット+最小限の数字差し替え。
   架空カード禁止。全画面の達成祝いは実装に存在しないため出さない (2026-08-12削除済を確認)。
3. **透明カバー残留禁止**: 暗幕・光・灰枠は pointer-events:none。終了時に必ずアンマウント
   (GuideOverlay.dom.test で担保)。
4. **初回1回だけ表示**: 進行・完了はサーバ側 (DB) 保存。localStorage禁止
   (WelcomeSlides の端末跨ぎ再表示の欠陥を繰り返さない)。完了/スキップ後は二度と出ない。
5. **自動送り禁止**: 例外は録音カウントダウンと、画面内で完結する演出
   (リング完成→達成カード出現、コインが埋まる) のみ。進行は実物タップ・カード内ボタン・
   「つづける」チップのタップで行う。
6. **文章に絵文字・再生記号を使わない**。UI文言に括弧を使わない (「・」区切り)。
7. **道しるべバー**: 通常はビューポート下端固定 (タブバーの上・スクロールで流れない)。
   対象が画面下部のときは上へ退避 (shirubeTop)。吹き出しと重なる採点結果2回目のみ
   最上部 (shirubeHigh top:0.6%)。録音中・全画面中はガイド層ごと非表示。
   説明ステップ (advTap) はバー右端に脈動する金の「つづける」チップを自動表示
   (チップ・画面のどちらをタップしても進む)。「タップでつづける」の文言は使わない。
8. **金の光=次に押す場所 / 灰枠=いま見る場所**。最初のページの金枠は%座標ではなく
   カードDOM自体の発光 (.goldhl) — フォント差でズレないため。
9. 失敗分岐 (低得点・無音) は**廃止**。WelcomeSlides と PageCoachMarks はガイド完成時に廃止・置換。

## 用語の正 (実装確認済)

- **達成** = 弾けるリングの3条件 (学びレッスン+エチュード+通して弾く3回)。90点ではない。
- **マスター** = 直近5回の平均90点以上。
- 達成→マイランクのゲージ/コイン加算 (page.tsx:203「新体系では『達成』数」)。
- 採点完了の吹き出し = CelebrationBanner の転写 (#1E3A8A ピル「採点できあがったよ！」・
  ふりかえりタブ中心の真上・下向きしっぽ・ふわっと出現)。1回目と2回目の両採点結果に表示。
- 現在のレベル = 採点前は非表示 (recentLevel null で非描画)。75-89点=いい調子・90+=ばっちり。
- 演奏の軌跡シートの実装ラベルは「マスターした曲」だが実カウントは達成数。
  モックは「達成した曲」。**ガイド実装時に本体ラベルの改名を提案する。**
